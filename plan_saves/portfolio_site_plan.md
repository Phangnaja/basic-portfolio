# Portfolio Website Plan: Vibram Certified Cobbler

## Objective
Create a professional, modern portfolio website for a Vibram-certified cobbler, Eakaphong Phang, hosted on GitHub Pages.

## Scope & Design Specifications
- **Theme:** Modern dark mode.
- **Typography:** Kanit font (via Google Fonts).
- **Structure:**
    - **Hero Section:** Name "Eakaphong Phang" and credentials "Vibram Certified Cobbler".
    - **Projects:** Showcase 3 distinct cobbling projects.
    - **Contact:** Clear contact details (email, social, or form link).

## Implementation Steps

### Phase 1: Setup
1. Create a new GitHub repository named `[your-username].github.io`.
2. Initialize with a `README.md` and clone to local environment.
3. Set up a simple project structure:
    - `index.html`
    - `style.css`
    - `assets/` (for images)

### Phase 2: Frontend Development
1. **HTML Structure:** Define semantic layout (Header, Hero, Portfolio Section, Contact).
2. **Styling:**
    - Apply Dark theme (background-color: #121212 or similar).
    - Import/Apply Kanit font from Google Fonts.
    - Create responsive CSS Grid/Flexbox layouts for project cards.
3. **Content:**
    - Fill in "Eakaphong Phang" and credentials.
    - Add 3 project placeholders (image + description).
    - Add contact section.

### Phase 3: Deployment
1. Commit changes to `main` branch.
2. Enable GitHub Pages in Repository Settings (point to `main` root).
3. Verify site at `https://[your-username].github.io`.

## Verification
- Validate accessibility (contrast ratios for dark mode).
- Ensure font-family "Kanit" loads correctly.
- Test responsive layout on mobile/desktop.
- Verify GitHub Pages deployment.
